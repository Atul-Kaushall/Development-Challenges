# 🚀 Development Challenges

A collection of JavaScript development challenges focused on building practical
frontend features and understanding core programming concepts.

This repository contains multiple mini-projects/challenges, each focused on
solving a specific problem using HTML, CSS, and JavaScript.

---

## 📂 Challenges

| Challenge | Topic | Description |
|-----------|-------|-------------|
| 01 | Price Finder | Find and filter products based on price |
| 03 | Recently Viewed | Track and display recently viewed products |
| 04 | Undo/Redo Cart | Implement undo and redo functionality for cart actions |
| 06 | Inventory Range | Filter products based on inventory range |
| 08 | Delivery Route | Work with delivery route and related logic |
